**Interfaces:**
- `manifest.py`:
  - `PageRecord`: Dataclass holding `document_id`, `page_id`, `page_number`, `source_path`, `file_sha256`, `content_sha256`, `split`, `extraction_method`, `review_status`.
  - `AliasRecord`: Dataclass holding `alias_id`, `canonical_page_id`, `source_reference`, `reason`, `review_status`.
  - `build_page_manifest(pages, split_assignment)` -> `List[PageRecord]`
  - `resolve_aliases(raw_page_refs, canonical_page_ids)` -> `Tuple[Dict[str, str], List[AliasRecord]]`
- `detector.py`:
  - `DuplicateRecord`: Dataclass holding `group_id`, `collision_type`, `left_page_id`, `right_page_id`, `content_sha256`, `split_leakage`, `resolution`, `review_status`.
  - `detect_content_duplicates(pages)` -> `List[DuplicateRecord]`
  - `detect_split_leakage(duplicate_records, page_manifest)` -> `List[DuplicateRecord]`
  - `verify_qrel_consistency(qrels, canonical_page_ids)` -> `Dict[str, Any]` (consistent_count, orphan_queries, missing_pages)
- `report.py`:
  - `export_manifest_csv(records, path)`
  - `export_alias_csv(records, path)`
  - `export_duplicate_csv(records, path)`
  - `generate_collision_markdown_report(summary)` -> `str`
