## Kết quả kiểm tra lần này

Môi trường `.venv`, Python 3.11; chạy từ thư mục gốc repo:

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

**69 test: 68 đạt, 1 skip quyền tạo symlink trên Windows; exit code 0.**
Trong đó 25 test M1.2 đều đạt. Log có exception `RuntimeError('expected')`
trong test giả lập lỗi stage; đó là tình huống test mong đợi, không phải run
nghiên cứu bị lỗi.

Lần kiểm chứng M1.2 sau cập nhật đặc tả dùng namespace mới:

```powershell
.venv/Scripts/python.exe scripts/verify_m12.py --config configs/m1.2/core.toml --output results/m1.2/handoff-check-2026-09-26
```

Xem [bằng chứng lần kiểm tra bàn giao](../results/m1.2/handoff-check-2026-09-26/README.md).
Các output có loại `synthetic_software_verification`, không phải kết quả
retrieval trên ViDoSeek. Review code riêng của công cụ không tìm thấy lỗi
critical/important trong phạm vi đã đọc; review đó không thay thế nghiệm thu
của thành viên nhóm.
