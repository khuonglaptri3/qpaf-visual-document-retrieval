# Manifest cho gói tài liệu hiện tại

Hai manifest này dùng để kiểm tra gói chuẩn bị local sau khi chuyển tài liệu vào folder:

- [ViMDoc archive audit](vimdoc_archive_content_audit_v1_preparation.json).
- [ViMDoc M3](vimdoc_m3_local_v1.json).

Mỗi manifest ghi nguồn lịch sử và SHA-256 của manifest gốc trong `documentation_migration`. Đường dẫn, kích thước và hash trong `files` áp dụng cho checkout hiện tại. Hồ sơ gốc trong `artifacts` giữ nguyên; việc chuyển folder không thay đổi kết quả nghiên cứu hoặc cấp quyền chạy thí nghiệm.

[Quay lại mục lục dữ liệu](../README.md).
