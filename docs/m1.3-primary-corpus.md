## 1. Mục tiêu và Quyết định Thiết kế

Bước M1.3 giải quyết lỗ hổng tài sản nghiên cứu bị phát hiện trong đợt audit trước
(trước đây M1.3 bị ghi "Done" ảo nhưng chưa có gói phần mềm kiểm chứng thực tế).

- **Tập dữ liệu chuẩn hóa:** Sử dụng **`Qiuchen-Wang/ViDoSeek`** tại
  `https://huggingface.co/datasets/Qiuchen-Wang/ViDoSeek` (pinned commit

  `configs/m1.1/vidoseek.toml` và adapter `src/qpaf/m11/dataset.py`.
- **Kiểm toán thuần CPU (`CPU-only`):** Toàn bộ pipeline kiểm kê, lập manifest,
  phân tách split và kiểm tra tính toàn vẹn chạy hoàn toàn trên CPU thông thường;
  không đòi hỏi GPU, không phát sinh chi phí tính toán đám mây.
- **Ranh giới an toàn đóng (`Closed Boundary Guard`):** Trạng thái cấp phép thực thi
  được kiểm soát chặt chẽ (`execution_authorized = false`). Mọi nỗ lực huấn luyện mô hình
  khi chưa có quyết định phê duyệt chính thức từ Gate G1 đều bị ngăn chặn.

## 2. Cấu trúc Phân hệ M1.3 (`src/qpaf/m13/`)

```text
src/qpaf/m13/
├── __init__.py           # Export các module và API công khai
├── boundary.py           # Quản lý ranh giới an toàn (Closed Boundary Guard)
├── corpus.py             # Kiểm kê archive PDF, quét thư mục và sinh fixture giả lập
├── splits.py             # Sinh và kiểm chứng phân chia split tất định (label-free)
└── vidoseek.py           # Phân tích cú pháp vidoseek.json, map page ID, kiểm tra qrels
```

### Quy tắc ánh xạ định danh:
- **Tài liệu (Document):** Tên tệp PDF gốc (ví dụ: `report_q3.pdf` $\rightarrow$ doc ID: `report_q3`).
- **Trang tài liệu (Page ID):** `{doc_stem}_page_{page_num:04d}` (chỉ số 1-based, 4 chữ số).
- **Phân tách Split:** Dùng thuật toán băm `SHA256(f"{namespace}:{seed}:{query_id}")`
  sắp xếp tất định không đọc nhãn, đảm bảo $\text{Train} \cap \text{Val} = \emptyset$,
  $\text{Train} \cap \text{Test} = \emptyset$, $\text{Val} \cap \text{Test} = \emptyset$.

## 3. Hướng dẫn Sử dụng Công cụ Dòng lệnh

### 3.1 Chạy kiểm kê với file cấu hình TOML:

```bash
python scripts/audit_primary_corpus.py --config configs/m1.1/vidoseek.toml --output results/m1.3/audit_report.json
```

### 3.2 Sinh và kiểm tra split manifest:

```bash
python scripts/audit_primary_corpus.py \
  --annotations /path/to/vidoseek.json \
  --splits-dir manifests/m1.3/ \
  --generate-splits
```

Công cụ sẽ tạo ra 3 tệp manifest chuẩn tắc:
- `train_ids.txt` (mỗi dòng một query ID)
- `val_ids.txt`
- `test_ids.txt`

### 3.3 Chạy kiểm tra ranh giới an toàn (Closed Boundary):

```bash
python scripts/audit_primary_corpus.py --check-boundary
```
