## Cách nhận và kiểm tra

Checkout nhánh PR hoặc develop sau merge, dùng Python với dependencies trong
`pyproject.toml`. Đăng nhập `gh` bằng tài khoản collaborator để xem draft asset.
Chạy từ repository root:

```powershell
gh release download m4.2-baseline-bundle-20261023 --repo khuonglaptri3/qpaf-visual-document-retrieval --pattern RUN-QPAF-M4_2-CAL-001-20261023T150631Z-A01.zip --dir .cache/m42-delivery
Get-FileHash .cache/m42-delivery/RUN-QPAF-M4_2-CAL-001-20261023T150631Z-A01.zip -Algorithm SHA256
```

Đối chiếu hash với bảng. Trong checkout đã có JSON/text của run, chỉ khôi phục
payload còn thiếu và kiểm bytes của file đã có. Đoạn sau không ghi đè file:

```powershell
@'
from pathlib import Path
import hashlib, zipfile
archive = Path('.cache/m42-delivery/RUN-QPAF-M4_2-CAL-001-20261023T150631Z-A01.zip')
assert hashlib.sha256(archive.read_bytes()).hexdigest() == '45e764f6bfe081063ea2488dbf5e26ffcaacf2e6f43ea3ad47f56a10c331d2d8'
root = Path('results/m4.2').resolve()
with zipfile.ZipFile(archive) as z:
    assert z.testzip() is None
    for name in z.namelist():
        target = (root / name).resolve()
        assert target.is_relative_to(root)
        data = z.read(name)
        if target.exists():
            assert target.read_bytes() == data, f'Existing artifact differs: {name}'
        else:
            target.parent.mkdir(parents=True, exist_ok=True)
            with target.open('xb') as stream:
                stream.write(data)
'@ | python -X utf8 -
python -X utf8 scripts/run_m42_active_primary.py --output results/m4.2/RUN-QPAF-M4_2-CAL-001-20261023T150631Z-A01 --verify --expected-manifest-sha256 4752eef37d7c6cf73eb36717bd352e21192d112b1464a3f5a61dab86bcc76b86
python -X utf8 -m unittest tests.test_m42_active_primary tests.test_m25_freeze tests.test_m42_baselines tests.test_m42_freeze tests.test_m41_confirmation_seal -q
```

  trên common rescored union. QARF checkpoint seed 20260820 đã bind hash.

  ở M4.4; strongest baseline phải chọn theo validation/protocol.

  normalization, splits và evaluator khi so sánh.
- Thay đổi fit space/normalization/model phải có version/evidence mới;
  không sửa baseline/run này để thích nghi với kết quả test.
