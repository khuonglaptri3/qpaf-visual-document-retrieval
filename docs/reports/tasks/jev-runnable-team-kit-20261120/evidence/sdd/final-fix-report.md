## Self-review and limits

The raw snapshots incur temporary disk usage proportional to the supplied raw files. Their digests describe the exact bytes consumed per file. Multiple independently supplied files can originate from different producer revisions. On Windows directory rename atomically refuses an existing destination. On POSIX the implementation reserves an empty destination with exclusive mkdir immediately before replacing it with the complete staged directory. A competing toolkit invocation cannot claim the same path. The tests ran on Windows. Ordinary failed staging cleans up and a retry uses a fresh output path.

The scope preserves the existing page-level training protocol and upstream scheduler. The pinned upstream trainer's ten-effective-step limitation and the matched-budget guidance are still documented. Full-size model quality, private data, GPU/cloud execution and training were outside this fix wave.
