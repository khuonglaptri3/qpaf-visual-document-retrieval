## Volume guidance

The fix report permits simultaneous jobs on a shared Volume when their output and chunk directories differ. The worker still points both at /data/.huggingface, so that setup shares writable paths. Document separate named Volumes for independent concurrent owners and strictly sequential reuse of a shared Volume. The local rename claim protects a coherent filesystem. Modal Volumes use last-write-wins for concurrent changes to the same file across independently mounted containers and lack distributed file locking.
